# Home tabs and launcher polish

Before: `main` at `c50af4c322307b66c306b709fdcecb69b49725a9`. After: #264. The Home Mods and empty-state captures use `c5d34483a2090eb68cfb1746d489e60fabcc9b7c`; the other unchanged screens use `cff038c9ede6d22181b5d1032040e4ad8bb56e1c`.

Actual Linux launcher client screenshots from X11, including the custom title bar. The account name, worlds, server addresses, packs and mods are fixtures. No game installation or account sign-in was used.

The old Home showed Worlds and Mods together; the dedicated Servers and Resource Packs tabs and the Profile options menu have no matching before state.
